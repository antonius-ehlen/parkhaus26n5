# Superparking auf GitHub Pages

Diese Version ist eine eigenständige statische Browser-App. Sie benötigt weder Node.js noch einen Build-Schritt und verändert das ursprüngliche Konsolenprogramm nicht.

## Lokal ausprobieren

`index.html` direkt im Browser öffnen.

## Auf GitHub Pages veröffentlichen

1. Das Repository auf GitHub pushen.
2. Unter **Settings → Pages** bei **Build and deployment** die Quelle **Deploy from a branch** wählen.
3. Den Branch `main` und den Ordner `/(root)` wählen und speichern.
4. Die Seite wird unter `https://<benutzername>.github.io/<repository>/docs/` erreichbar.

Bei einer benutzerdefinierten Domain oder einem Repository, das als `<benutzername>.github.io` veröffentlicht wird, kann die URL entsprechend abweichen.
